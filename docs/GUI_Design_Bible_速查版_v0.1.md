# EOR GUI Design Bible（速查版）

> v0.1 讨论稿
> 来源：EOR_GUI_Design_Spec.md + EOR_GUI_Prototype.html
> 用途：SA/DA 在 GUI 开发与验收时的统一视觉参考，无需翻阅整本 Design Spec

---

## 1. 配色方案

### 1.1 主题色

| 用途 | 色名 | 色值 | 备注 |
|------|------|------|------|
| 全局背景 | 羊皮纸色 | `#FFF8F0` | 主内容区背景 |
| 面板背景 | 浅羊皮纸 | `#FFF5E6` | 左/右侧面板 |
| 标题栏 | 罗马深红 | `#8B2500` | Header Bar、重要标题背景 |
| 面板边框 | 古铜色 | `#D4A574` | 所有面板边框 |
| 金色 | 金色 | `#FFD700` | 标题文字、高亮元素 |
| 当前阶段高亮 | 金色变体 | `#E8B84B` | 阶段进度条当前项 |
| 已完成阶段 | 秘鲁色 | `#CD853F` | 阶段进度条已完成项 |
| 按钮背景 | 原木色 | `#DEB887` | 操作按钮默认色 |

### 1.2 派系色

| 派系 | 色值 | CSS 变量 | 用途 |
|------|------|----------|------|
| Optimates（贵族） | `#8B0000` | `--opt` | 深红，玩家默认派系 |
| Populares（平民） | `#006400` | `--pop` | 深绿 |
| Equites（骑士） | `#00008B` | `--equ` | 深蓝 |

### 1.3 语义色

| 语义 | 色值 | 用途 |
|------|------|------|
| 成功/通过 | `#228B22` | 正面反馈、通过标记 |
| 警告 | `#FF8C00` | 风险提示 |
| 危险/失败 | `#8B0000` | 失败、危机、扣减 |

## 2. 布局框架

### 2.1 全局 4 区域结构

```
+-------------------------------------------------------------+
|  [HEADER]  8% 高度                                           |
+--------+----------------------------+-----------------------+
| LEFT   |        CENTER              |        RIGHT          |
| 22%    |        54%                 |        24%            |
| (min 200px)                         | (min 220px)           |
+--------+----------------------------+-----------------------+
|  [BOTTOM]  ~4% 高度                                         |
+-------------------------------------------------------------+
```

### 2.2 区域间距

| 间距 | 值 |
|------|----|
| 面板间间隔 | `10px` |
| 面板内边距 | `12px` |
| 标题与内容间距 | `10px`（border-bottom + padding-bottom） |
| 阶段进度条按钮间距 | `4px`（gap） |

## 3. 字体与排版

| 用途 | 字号 | 粗细 | 颜色 |
|------|------|------|------|
| Logo | `1.3rem` | Bold | `#FFD700` |
| 回合信息 | `1.1rem` | Bold | `#FFFFFF` |
| 阶段按钮文字 | `0.75rem` | Bold | 未完成: `#666` / 当前: `#FFF` |
| 面板标题 | `0.95rem` | — | `#8B2500`（罗马深红） |
| 正文 | `0.9rem` | — | — |

字族：`'Segoe UI', 'Microsoft YaHei', 'SimHei', sans-serif`

## 4. 圆角与阴影

| 元素 | 圆角 | 阴影 |
|------|------|------|
| 面板 | `8px` | — |
| 阶段按钮 | `4px` | — |
| 当前阶段按钮 | `4px` | `0 0 10px rgba(232,184,75,0.5)` |
| Header | — | `0 2px 8px rgba(0,0,0,0.3)` |

    --pop: #006400;
