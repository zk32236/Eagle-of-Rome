## 1. 诊断摘要

### 问题 A: 主内容区空白（P0）

**根因：** Advance 区域 visibility 条件自相矛盾。

`get_combat_view()` 在 `len(active_wars) == 0` 时设置 `current_step = "advance"`。但 advance 区域的 QML visibility 条件为：
```qml
visible: root.combatStep === "advance" && sessionStore.hasActiveWars
```
`sessionStore.hasActiveWars` 计算自 `len(active_wars) > 0`。当所有战争已结算（进入 advance 步骤），`active_wars` 为空 → `hasActiveWars = false` → advance 区域隐藏。

此时 CombatStage 所有子组件均不可见：
- `militaryOverviewBar` → 需 `hasActiveWars` → ❌ 隐藏
- War card 容器 → 需 step=select/action → ❌ 隐藏
- Result 区域 → 需 step=result → ❌ 隐藏
- Advance 区域 → 需 step=advance AND hasActiveWars → ❌ 隐藏

**结果：** 页面呈现完全空白的主内容区，仅保留来自 GameShell 的 header 和 step bar。

### 问题 B: 标题重叠/裁切（P0）

**根因：** Generic fallback header 未排除 combat phase。

GameShell.qml 的 StageDesktop 标题区存在两个 ColumnLayout：
1. **Combat 特定标题**：`visible: sessionStore.selectedPhaseId === "combat"` — badge "6/7" + 标题 + 说明
2. **通用 fallback 标题**：`visible: selectedPhaseId !== "mortality" && !== "revenue" && !== "forum" && !== "population" && !== "senate"` — **未排除 "combat"**

当 `selectedPhaseId === "combat"` 时两套标题同时渲染，两套标题（badge、标题、说明文字）叠加在 80px 的固定高度容器内，造成文字重叠、裁切、叠字。
