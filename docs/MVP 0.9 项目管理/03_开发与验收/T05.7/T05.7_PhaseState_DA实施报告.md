### 1.2 关键发现：PhaseRail 使用 `"war"` 而非 `"combat"`

```
┌──────────────────────────────────────────────────────────────────────┐
│                    Phase ID 不一致 —— 根本原因                         │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  GameShell.qml:         selectedPhaseId === "combat"  ← ✅ 标准      │
│  CombatStage.qml:       visible: "combat"             ← ✅ 标准      │
│  StageDesktop headers:  visible: "combat"             ← ✅ 标准      │
│  ContextPanel:          sessionStore.selectedPhaseId   ← ✅ 动态读取 │
│  → → → → → → → → → → → → → → → → → → → → → → →                    │
│  PhaseRail.qml:         selectedPhaseId === "war"     ← ❌ 偏差      │
│  PhaseRail onClicked:   selectPhase("war")            ← ❌ 偏差      │
│                                                                      │
│  影响链路：                                                          │
│  1. PhaseRail 检查 "war" → 永远不匹配 "combat" → 无金色高亮          │
│  2. 用户点击战斗图标 → selectPhase("war") → store 设置 "war"         │
│  3. GameShell 检查 "combat" → 不匹配 → CombatStage 隐藏              │
│  4. ContextPanel 读取 "war" 的 phase data → 返回错误上下文            │
└──────────────────────────────────────────────────────────────────────┘
```

这是**历史遗留命名问题**：PhaseRail 在早期原型阶段使用 `"war"` 作为战斗阶段 ID，后续迭代中所有其他组件统一为 `"combat"`，但 PhaseRail 未被同步更新。

## 3. 修改详情

### 3.1 PhaseRail.qml — 修正 Combat Phase ID（P1 根因修复）

**问题：** PhaseRail 使用 `"war"` 作为 combat phase 的唯一标识符，与其他所有组件使用的 `"combat"` 不一致。导致：
- 任何阶段下 `sessionStore.selectedPhaseId === "war"` 均不成立 → 战斗按钮始终 dark
- 点击战斗按钮调用 `sessionStore.selectPhase("war")` → store 设置错误 ID → 所有检测 `"combat"` 的组件均不显示

**修复：** 将 combat phase 的 ID 从 `"war"` 同步为 `"combat"`

```diff
         PhaseRailIcon {
-            objectName: "phaseRailIcon_war"
+            objectName: "phaseRailIcon_combat"
             iconText: "⚔️"; label: "战斗"
-            state: sessionStore.selectedPhaseId === "war" ? "current" : (sessionStore.currentPhaseIndex > 5 ? "done" : "todo")
-            onClicked: sessionStore.selectPhase("war")
+            state: sessionStore.selectedPhaseId === "combat" ? "current" : (sessionStore.currentPhaseIndex > 5 ? "done" : "todo")
+            onClicked: sessionStore.selectPhase("combat")
         }
```

### 3.2 GameShell.qml — 动态化 Combat Header 标题（P1 中央面板修复）

**问题：** Combat phase header 标题固定显示 "⚔️ 战斗阶段 — 战场指挥"，即使在 SELECT 状态也显示子步骤 "战场指挥"。SELECT 状态应仅显示阶段名称，不显示子步骤标题。

**修复：** 根据 `sessionStore.combatCurrentStep` 动态切换子步骤显示

```diff
                 Text {
-                    text: "⚔️ 战斗阶段 — 战场指挥"
+                    text: "⚔️ 战斗阶段" + (sessionStore.combatCurrentStep === "action" ? " — 战场指挥" :
+                        sessionStore.combatCurrentStep === "result" ? " — 查看战果" :
+                        sessionStore.combatCurrentStep === "advance" ? " — 推进决算" : "")
                     color: "#681B07"
```

**状态映射：**

| combatCurrentStep | 显示的标题 |
|:-----------------:|:----------:|
| `"select"` (或未定义) | ⚔️ 战斗阶段 |
| `"action"` | ⚔️ 战斗阶段 — 战场指挥 |
| `"result"` | ⚔️ 战斗阶段 — 查看战果 |
| `"advance"` | ⚔️ 战斗阶段 — 推进决算 |
