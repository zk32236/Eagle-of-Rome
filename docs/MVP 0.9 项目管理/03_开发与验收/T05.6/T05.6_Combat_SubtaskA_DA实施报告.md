### A-3: `get_combat_view()` 加入已解决战争数据

**File:** `src/api/combat_api.py` — `get_combat_view()` function

**Change:** Added resolved war card generation and DTO fields.

```python
# After the active wars war_cards section:
# Build resolved war cards from war_system discard pile, filtered by phase_data
resolved_war_ids = resolved_wars  # list of war_ids from phase_data
resolved_wars_full = ws.get_resolved_wars() if ws else []
relevant_resolved = [w for w in resolved_wars_full if w.id in resolved_war_ids]
resolved_war_cards = [_war_card(w, state) for w in relevant_resolved]
```

Added to data DTO:
```python
"resolved_war_cards": resolved_war_cards,
"resolved_war_ids": resolved_war_ids,
```

**DTO Changes:**

| Field | Type | Always present | Source |
|-------|------|:--------------:|--------|
| `resolved_war_cards` | list[dict] | ✅ (may be []) | `ws.get_resolved_wars()` filtered by `phase_data["resolved_wars"]` |
| `resolved_war_ids` | list[str] | ✅ (may be []) | Direct from `phase_data["resolved_wars"]` |

**Architecture Decision:** The single source of truth for resolved war tracking remains in Python (`phase_data["resolved_wars"]`). The QML side uses `combatResolvedWarIds` instead of the removed `_resolvedWarIds` array.

### A-4: Store 层新增 QML Property

**File:** `src/ui/gui/session_store.py` — combat stage properties section (after `hasActiveWars`)

**Change:** Added 3 new QML-accessible properties:

```python
@Property(list, notify=combatViewChanged)
def combatResolvedWarCards(self) -> List[Dict[str, Any]]:
    return self._combat_view.get("resolved_war_cards", [])

@Property(list, notify=combatViewChanged)
def combatResolvedWarIds(self) -> List[str]:
    return self._combat_view.get("resolved_war_ids", [])

@Property(list, notify=combatViewChanged)
def combatAllWarCards(self) -> List[Dict[str, Any]]:
    """Combined list of active + resolved war cards for QML Repeater."""
    active = self._combat_view.get("active_wars", [])
    resolved = self._combat_view.get("resolved_war_cards", [])
    return active + resolved
```

**Properties Summary:**

| Property | Type | notify | Source |
|----------|------|--------|--------|
| `combatResolvedWarCards` | list[dict] | `combatViewChanged` | `_combat_view["resolved_war_cards"]` |
| `combatResolvedWarIds` | list[str] | `combatViewChanged` | `_combat_view["resolved_war_ids"]` |
| `combatAllWarCards` | list[dict] | `combatViewChanged` | active + resolved war cards concatenated |
