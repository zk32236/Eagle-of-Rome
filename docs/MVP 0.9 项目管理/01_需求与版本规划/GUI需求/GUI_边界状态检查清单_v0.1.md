# GUI 边界状态检查清单

> v0.1 讨论稿
> 用途：DA 自验和 SA 验收时，逐一检查 GUI 组件在非正常状态下的行为

---

## 使用说明

- DA 在完成实现后，用此清单进行边界测试
- SA 在验收时抽样检查清单中的项目
- 每个组件至少验证：空数据态、加载态、错误态、极限数据

---

## 1. 空数据态（Empty State）

检查当后端返回空数据时，组件是否正常显示（不崩溃、不白屏）。

| 检查项 | 适用组件 | 预期行为 | 通过 |
|--------|---------|---------|------|
| 列表为空 | 人物列表、候选人列表、事件日志 | 显示「暂无数据」提示或保持空白布局不崩 | [ ] |
| 国库为零 | 国库显示区 | 显示 `0` 或 `0T`，不显示负数格式 | [ ] |
| 无候选人 | 投票区 | 显示「本职位无候选人」 | [ ] |
| 无可用操作 | 操作按钮区 | 按钮置灰或提示「当前无可执行操作」 | [ ] |
| 无事件 | 天命阶段事件卡 | 显示「神明沉默」或跳过该阶段 | [ ] |

## 2. 加载态（Loading State）

检查组件在数据尚未就绪时的表现。

| 检查项 | 适用组件 | 预期行为 | 通过 |
|--------|---------|---------|------|
| 数据加载中 | 列表/表格 | 显示加载指示器或骨架屏 | [ ] |
| 截图加载中 | 人物头像/图标 | 显示占位图或加载中 | [ ] |
| 阶段切换过渡 | 所有阶段 | 切换时显示过渡动画或短暂 loading | [ ] |

## 3. 错误态（Error State）

检查后端返回错误或数据异常时的表现。

| 检查项 | 适用组件 | 预期行为 | 通过 |
|--------|---------|---------|------|
| 数据加载失败 | 列表/表格 | 显示错误提示 + 重试按钮（如适用） | [ ] |
| 非法数据值 | 数值显示区 | 负数显示为错误态颜色，值为 null 时降级为 `--` 或 `0` | [ ] |
| 网络断开 | 全局 | 不会导致崩溃，显示离线提示（可选） | [ ] |
| 存档损坏 | 全局 | 提示存档错误，不崩溃 | [ ] |

## 4. 极限数据（Extreme State）

检查极端输入或数据量下的表现。

| 检查项 | 适用组件 | 预期行为 | 通过 |
|--------|---------|---------|------|
| 超长人物姓名 | 人物列表 | 文字截断显示 `...`，不撑破布局 | [ ] |
| 超长事件描述 | 事件卡/日志 | 文字折叠或截断 + tooltip 全文 | [ ] |
| 超大数值 | 国库/影响力 | 数值格式化（如 `1,234,567T`），不溢出 | [ ] |
| 超多候选人 | 投票列表 | 可滚动，不卡死 | [ ] |
| 超多事件 | 事件日志 | 限制显示条数（如最近 20 条）+ 滚动 | [ ] |
| 最小窗口 | 全局（1024×768） | 布局不重叠，关键信息可见 | [ ] |
| 最大窗口 | 全局（1920×1080） | 布局不拉伸变形 | [ ] |

## 5. 交互边界（Interaction Edge Cases）

| 检查项 | 适用组件 | 预期行为 | 通过 |
|--------|---------|---------|------|
| 快速双击按钮 | 所有操作按钮 | 防抖，不触发两次操作 | [ ] |
| 连续快速切换阶段 | 阶段进度条 | 切换稳定，不会跳过阶段 | [ ] |
| 空选中项时执行操作 | 操作按钮 | 提示「请先选择目标」 | [ ] |
| 负值输入 | 输入框 | 校验拒绝或自动取绝对值 | [ ] |
