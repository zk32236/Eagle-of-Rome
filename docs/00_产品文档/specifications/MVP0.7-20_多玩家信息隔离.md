# MVP0.7-20 — 多玩家信息隔离

> **功能简述：** 多玩家模式下命令层的信息隔离方法、提示符前缀、玩家身份校验

## 1. 功能目的

确保多玩家模式下信息隔离：玩家只能查看自己的派系信息，无法获取对手的私密数据。

## 2. 核心规则

### 2.1 信息隔离层级

| 数据类型 | 可见性 |
|---------|--------|
| 国家资源 | 所有玩家公开 |
| 本派系成员 | 仅本派系 |
| 本派系资源 | 仅本派系 |
| 其他派系资源 | 不可见 |

### 2.2 CLI 提示符

`[Player1 贵族派] >` 形式，AI 不占据交互位。
