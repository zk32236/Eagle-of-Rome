# MVP0.7-07 — 天降猛男

> **功能简述：** 天命阶段"天降猛男"事件触发后，标记一位历史英雄在后续广场阶段登场。

## 1. 功能目的

模拟罗马历史上英雄人物的涌现。事件触发后，系统在广场阶段的人物生成流程中插入一位属性远超普通人的特殊人物。

## 2. 核心规则

### 2.1 英雄可用性判定

`birth_year + 16 <= current_year <= death_year`

### 2.2 重复保护

- 同一历史英雄在整个游戏中只出现一次
- 所有可用英雄均出现过 → 随机猛人模式
