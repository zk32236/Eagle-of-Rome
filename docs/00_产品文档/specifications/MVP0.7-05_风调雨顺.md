# MVP0.7-05 — 风调雨顺

> **功能简述：** 天命阶段"风调雨顺"事件触发后，本回合全国土地产出按配置倍率加成。

## 1. 功能目的

模拟罗马气象条件有利的自然事件。触发后为全国土地收入赋予临时的百分比加成，增加游戏随机性和策略弹性。

## 2. 核心规则

### 2.1 配置

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `mortality_rules.bumper_harvest_multiplier` | float | `1.5` | 土地产出乘数 |

### 2.2 加成算法

- 加成百分比 = `(multiplier - 1) * 100`（默认 50%）
- 作用域：国家公地收入 + 人物私地收入 + 包税合同利润
- 一次性效果：仅在触发本回合生效
