# MVP0.7-28-sys — Curia广场等待区实体

> **功能简述：** Curia dataclass：存放等待被招募的人物，提供队列管理与招募审计

## 1. 功能目的

Curia（广场等待区）是罗马广场上所有可供招募人物的汇聚池，提供数据容器和队列管理方法。

## 2. 核心规则

### 2.1 人物进入 Curia 的条件

| 来源 | 触发时机 |
|------|----------|
| 新人物生成 | 广场阶段开始时 |
| 天降猛男 | 广场阶段开始时 |
| 派系裁员 | 裁员环节 |

### 2.2 人物离开 Curia 的条件

| 去向 | 触发时机 |
|------|----------|
| 招募中标 | 公示结算 |
| 说服加入 | Persuade 命令 |
| 回合清理 | 推进回合 |
